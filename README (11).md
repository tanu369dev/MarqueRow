# Riders

A marketplace website for buying and selling luxury bikes. Plain HTML, CSS and JavaScript, with no build step.

All listings are sample data. Edit the `BIKES` list at the top of `script.js` to change bikes, prices and photos.

## Files

- `index.html` – the page
- `style.css` – styles
- `script.js` – listings, filters, spec sheet and sell form
- `images/` – bike photos

## Run locally

Open `index.html` in a browser.

## Publish on GitHub Pages

1. Create a new repository on GitHub and upload all these files, keeping the `images` folder.
2. Open Settings, then Pages.
3. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
